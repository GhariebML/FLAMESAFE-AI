# NASA PSI Investigations Explorer (`/investigations`, `/investigations/[id]`)

**Status:** `IMPLEMENTED AND TESTED`  
**Frontend Routes:** `frontend/app/investigations/page.tsx`, `frontend/app/investigations/[id]/page.tsx`  
**Backend Endpoints:** `GET /api/v1/investigations`, `GET /api/v1/investigations/{investigation_id}`

Search and filter indexed NASA Physical Sciences Informatics (PSI) campaigns by research area, fuel type, and gravity regime, and inspect run-level conditions, measurements, and DOI-linked source documents.
