# Data Observatory (`/compare`)

**Status:** `IMPLEMENTED AND TESTED`  
**Frontend Route:** `frontend/app/compare/page.tsx`  
**Backend Endpoint:** `POST /api/v1/compare`

Compares 2 to 4 NASA PSI investigations side-by-side with unit-matched numeric averages, normalized radar coverage charts, terrestrial (`1.0g`) vs. orbital (`~0g`) vs. extrapolated lunar (`0.16g`) regime comparisons, and CSV/JSON matrix exports.
