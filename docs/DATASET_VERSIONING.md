# FlameSafe AI — Reproducible Dataset Versioning Specification

## 1. Cryptographic Content Fingerprinting

Every dataset version generated by **Agent 10 (Dynamic Dataset Builder Agent)** computes a deterministic SHA-256 `content_fingerprint` over the canonical sorted records:

$$\text{Fingerprint} = \text{SHA256}\left(\text{CanonicalSort}\left(\{(I_k, R_k, P_k, V_k, U_k, \text{O}_{2,k}, P_{\text{kPa},k}, v_{\text{flow},k})\}_{k=1}^{N}\right)\right)$$

---

## 2. Version Lifecycle & Reuse Rules

1. **Exact Fingerprint Match (Idempotent Reuse)**:
   - If a `DatasetVersion` already exists in `dataset_versions` with the identical `content_fingerprint`, Agent 10 reuses the existing version (`reused_existing = True`) rather than duplicating rows or files.
2. **Dataset Key Match with Updated Records (Version Increment)**:
   - When new NASA PSI files or experimental runs are added for an existing `dataset_key`, `latest_version_number` increments ($1 \to 2 \dots$) and a new `DatasetVersion` (`v2.0.0`) is created with its own `DatasetValidationReport` and export snapshots.
3. **Multi-Format Immutable Snapshots**:
   - Each version writes `.json`, `.csv`, and `.parquet` artifacts under `data/vault/exports/<dataset_key>/<version_tag>/`.
